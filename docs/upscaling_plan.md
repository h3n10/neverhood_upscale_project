_Generated 2026-10-25 by `work_directory/tools/gen_docs.py`; checklist marks are preserved on regeneration._

## How to update marks

- Legend: `[x]` done, `[~]` partial/on hold, `[ ]` open. Edit this file by hand (change the character inside the brackets; keep the `<!--k:...-->` comment), or use the helper:
  - `python work_directory/tools/gen_docs.py --mark item:arc.c.extract --state x`
  - `python work_directory/tools/gen_docs.py --mark video:c.blb:0-84 --stage U --state x` (stages E F U Q R; ranges `a-b`, lists `1,5,9`, `*` = all)
- Re-running `python work_directory/tools/gen_docs.py` regenerates `docs/game_tree.md` and this file from the archives and keeps your marks.
- Video stages: **E** extracted (raw SMK + metadata), **F** frames decoded, **U** upscaled, **Q** QA gate passed, **R** repacked/playable in game.
- Same IDs as `extract_all.py` (`<archive>#<entry id>`).
